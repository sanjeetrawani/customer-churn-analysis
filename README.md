# Customer Churn Analysis – Churn Intelligence Dashboard

## 📌 Project Overview

This project is a Customer Churn Analysis and Interactive
Streamlit Dashboard designed to analyze customer churn,
retention, revenue at risk, customer segments, and support signals.

The project uses a SQLite database and performs data extraction,
data cleaning, feature engineering, analysis, and visualization.

## 🎯 Objectives

- Analyze customer churn behavior
- Calculate churn and retention rates
- Identify customers at different churn-risk levels
- Analyze churn by plan type and contract type
- Analyze churn across different states
- Analyze subscription sources
- Understand the relationship between escalations and churn
- Analyze revenue at risk
- Create an interactive dashboard

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- SQLite
- SQL
- Jupyter Notebook
- Matplotlib
- Seaborn
- Streamlit
